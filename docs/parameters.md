# Parameters and definitions

Generated by `pipeline.glossary` — do not edit by hand.

## Tunable constants

Every value below lives in `pipeline/config.py`. Nothing here encodes the contents of a particular database; these are method and design constants a formulator would genuinely re-specify for a new study.

| constant | what it is | units | current value and guidance |
|---|---|---|---|
| `VESSEL_VOLUME_ML` | Dissolution vessel volume, used to convert assay concentration into % released. | mL | Currently 900 mL. Not present in the raw file, so it must be set here. **Careful:** it scales every % released value. A wrong volume rescales the whole study without any error appearing. |
| `PLOT_MAX_TIME_H` | Upper limit of the time axis on every plot. | hours | Currently 25 h. Edit in pipeline/config.py. |
| `PLOT_MAX_RELEASE_PCT` | Upper limit of the release axis on every plot. | % released | Currently 115%. Above 100 on purpose, so real overshoot near plateau is visible rather than clipped. |
| `CENSORING_PCT` | Release level defining t80 and the censoring flag. | % released | Currently 80%. |
| `PEPPAS_MAX_PCT` | Upper release level of the portion the Peppas power law is fitted on. | % released | Currently 60%. The power law only describes the early, pre-plateau part of a release curve. |
| `PEPPAS_MIN_POINTS` | Fewest points required inside the Peppas window before k and n are reported at all. | count | Currently 3. Below this, no exponent is reported rather than an unreliable one. |
| `F2_SIMILAR_THRESHOLD` | f2 value at or above which two profiles are called similar. | dimensionless | Currently 50, the regulatory convention. |
| `F2_PLATEAU_PCT` | At most one timepoint beyond this release level enters an f2 calculation. | % released | Currently 85%. Stops the plateau, where all profiles agree, from dominating the statistic. |
| `MAX_PHYSICAL_RELEASE_PCT` | Lower bound for the ceiling placed on the fitted Weibull asymptote. | % released | Currently 105%. The ceiling actually applied is the larger of this and the profile's own peak times a margin. **Careful:** it exists to stop a censored profile's asymptote running off to nothing physical, not to assert that release cannot exceed it. |
| `ASYMPTOTE_IDENTIFIED_FRACTION` | How close to its fitted plateau a profile must climb before that plateau counts as estimated rather than extrapolated. | fraction | Currently 0.8. Profiles below it are flagged, because their Td is an extrapolation. |
| `TIME_CLUSTER_REL` | How far apart two timestamps may be and still count as the same nominal sample, as a fraction of the elapsed time. | fraction | Currently 0.01. Real sampling lands seconds to a minute off nominal; this reconciles it. **Careful:** too large and distinct pulls merge, silently lowering the time resolution of every profile comparison. The diagnostics warn when that happens. |
| `R2_GAP_FLAG` | Gap between adjusted and predicted R2 beyond which over-fitting is flagged. | dimensionless | Currently 0.2. |
| `ADEQUATE_PRECISION_FLAG` | Signal-to-noise ratio below which a surface is flagged as unfit for optimisation. | dimensionless | Currently 4, the conventional value. |
| `PIPELINE_SEED` | Seed for every resample, cross-validation split and optimiser start. | integer | Currently 8314159. Fixed so two runs produce byte-identical output. |

## Release metrics

| metric | definition | units | how to read it |
|---|---|---|---|
| t50 | Time at which 50% of the dose has been released. | hours | Lower means faster release. **Careful:** undefined when a formulation never reaches 50%, in which case it is reported as censored rather than as a number. |
| t80 | Time at which 80% of the dose has been released. | hours | The conventional marker for practically complete release. **Careful:** many controlled-release formulations never reach 80% within 24 h. Those are censored (>24 h), not missing, and dropping them would bias every summary toward the fast formulations. |
| MDT | Mean dissolution time: the average time a drug molecule spends in the tablet before release, obtained by integrating the whole curve. | hours | A single summary of overall release rate that uses every timepoint rather than one crossing. **Careful:** for a profile still rising at the last measurement it is a lower bound over the observed window, not the true MDT. |
| % released | Percentage of the labelled dose released at a given time. | % of dose | Computed as concentration x vessel volume / dose. **Careful:** values above 100% are ordinary near plateau. A one-sided offset across many formulations suggests the dose denominator is understated rather than that the assay is noisy. |
| Td (Weibull scale) | Weibull scale parameter: the time constant of the fitted release curve. | hours | Larger means slower release. Modelled on a log scale because release times are log-normal. **Careful:** for a profile that never approaches its own plateau, Td is extrapolated rather than estimated and carries far more uncertainty than the headline error suggests. |
| beta (Weibull shape) | Weibull shape parameter: controls the form of the curve independently of its timing. | dimensionless | Below 1 gives steep early release tailing off; near 1 is first-order-like; above 1 gives a sigmoidal curve with a lag. |
| F_inf (asymptote) | The fraction of dose the fitted curve approaches at infinite time. | % of dose | How much of the dose the formulation ultimately releases. **Careful:** only identified when the profile actually climbs near it. For slow formulations it is an extrapolation. |
| Peppas n | Exponent of the Korsmeyer-Peppas power law, a release-mechanism indicator. | dimensionless | Around 0.45 suggests Fickian diffusion; around 0.89 suggests erosion-controlled release; between the two suggests both operating. **Careful:** only valid on the portion of the curve at or below 60% released, and not reported at all when fewer than three points fall in that window. |
| f2 similarity | Similarity factor between two release profiles. 100 means identical. | dimensionless, 0-100 | At or above 50 the profiles are conventionally considered similar. **Careful:** the value depends heavily on which timepoints are used. Here it is computed with at most one point past 85% release, so the plateau cannot dominate a front-loaded sampling schedule. |

## Model and design statistics

| statistic | definition | how to read it |
|---|---|---|
| R2 | Fraction of the variation in the response explained by the model. | Higher is better, but it never decreases when terms are added. **Careful:** on its own it says nothing about prediction. A model can have R2 near 1 and still predict a new formulation badly. |
| adjusted R2 | R2 penalised for the number of terms in the model. | Comparable between models of different size, unlike raw R2. |
| predicted R2 (PRESS) | R2 computed from leave-one-out predictions rather than from the fit. | This is the honest one: it estimates how well the model predicts a point it has not seen. **Careful:** a large gap below adjusted R2 means the model describes this data better than it predicts new data, i.e. it is over-fitted. |
| adequate precision | Signal-to-noise ratio: the range of predicted values divided by their average prediction error. | Above 4 the surface can be used to navigate the design space. **Careful:** below 4 the modelled signal is not large enough against its own noise, and the surface must not be used for optimisation. |
| p | Probability of seeing an effect this large if the term truly had none. | Below 0.05 is conventionally called significant. **Careful:** significance is not importance. With enough replicates a trivially small effect becomes significant; read the effect size alongside it. |
| lack of fit | Test of whether the model's error exceeds the experiment's own repeatability, i.e. whether the model shape is wrong. | A significant result suggests the model form is inadequate. **Careful:** here the replicates are vessels from one compression batch, so pure error excludes batch-to-batch variation. The denominator is too small and the test will over-declare lack of fit. |
| cross-validated error | Root-mean-square prediction error from leave-one-formulation-out cross-validation, in percentage points of dose released. | The uncertainty on a prediction for a formulation the model has never seen. This is the number attached to every prediction here. **Careful:** do not confuse it with the replicate SD, which is within-batch analytical repeatability -- a much smaller number measuring something else entirely. |
| replicate SD | Standard deviation across the replicate vessels of one formulation. | How repeatable the measurement is within a single compression batch. **Careful:** this is NOT prediction error and must never be shown in its place. Batch-to-batch variation is unmeasured in this design. |
| leverage | How much influence one design point has over its own fitted value. | Points near 1 are barely checked by the rest of the design. |
| Cook's distance | How much every fitted value would shift if this point were removed. | Values above 1 mark a point worth inspecting. |
| VIF | Variance inflation factor: how much a coefficient's variance is inflated by correlation with the other terms. | Above about 10 the term is hard to separate from the others. **Careful:** infinite VIF means an exact dependency, not merely a strong one -- which is what a constant-sum mixture produces by construction. |
| scaled prediction variance | Prediction variance across the design region, scaled by the number of runs so designs of different size can be compared. | Lower and flatter is better: predictions are then uniformly trustworthy across the region rather than only near the design points. |
| D-criterion | Determinant-based measure of how much information the design carries about the model coefficients. | Higher is better. Comparable between rows of the same table only. **Careful:** not a percentage of an optimal design; a true D-efficiency needs a D-optimal reference for the same model and region. |
| G-efficiency | Worst-case prediction variance relative to the theoretical best. | Higher is better; this one is a genuine percentage. |
| Box-Cox lambda | The power transformation best matching the response to a normal distribution. | Lambda near 0 recommends a log transform; near 1 recommends none. **Careful:** read the confidence interval, not the point estimate. Lambda is rarely exactly 0 or 1, and rounding it without the interval applies a transformation the data may not support. |
| desirability | Derringer-Suich score combining several responses into one number between 0 and 1. | 1 means every goal met perfectly; 0 means at least one goal missed entirely. **Careful:** the weights are a judgement, not a measurement. Two candidates with similar scores are not distinguished by the data. |
| censored value | A value known only to lie beyond the observation window, e.g. t80 > 24 h. | Censored is not missing: the experiment did happen, and the answer is known to be large. **Careful:** dropping censored values biases every summary toward the fast formulations, which in a controlled-release study is precisely backwards. |
